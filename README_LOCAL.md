# Норма — локальная версия

## Windows 10 / 11

1. Полностью распакуйте архив в любую папку.
2. Дважды нажмите **Запустить.bat**.
3. Откроется браузер по адресу **http://127.0.0.1:4267/**.

Окно запуска оставьте открытым. Закрытие окна или Ctrl+C останавливает сервер.
Не открывайте `app/index.html` двойным щелчком: приложению нужен локальный HTTP-адрес.

Установка npm-пакетов для обычного запуска не нужна. Если установлены Node.js
или Python, запуск использует их. В остальных случаях используется штатный
Windows PowerShell и .NET Framework. Права администратора не требуются.
В Windows с корпоративным запретом PowerShell используйте Node.js или Python.
Сценарий запуска не меняет постоянные настройки PowerShell.

Для чтения графа, поиска, просмотра исходных файлов, импорта и экспорта интернет
не нужен. Все данные и библиотеки интерфейса уже в архиве. Ссылки «GitHub»
открывают внешний сайт только при нажатии.

## Что находится в архиве

- `app/` — готовая сборка с 21 JSON-LD, 298 узлами, 560 связями и 15 требованиями.
- `Запустить.bat` — запуск под Windows.
- `start-local.cjs` — сервер без зависимостей для Node.js.
- `start-local.py` — сервер на стандартной библиотеке Python 3.8+.
- `start-local.ps1` и `local-server.cs` — запасной запуск средствами Windows.
- `start-local.sh` — запуск в macOS/Linux.
- `source/` — исходники, исходные данные, тесты и инструкция для разработки.
- `licenses/` — лицензии используемых компонентов.

Приложение использует только адрес 127.0.0.1 на вашем компьютере. Оно не
публикует локальную копию в интернете и не загружает импортированные файлы
на удалённый сервер. Импортированные проекты сохраняются в данных браузера
для адреса http://127.0.0.1:4267/. Для переноса проекта в другой браузер используйте
«Экспорт графа», затем «Импорт». Очистка данных браузера удаляет локальные импорты.

Сохраняйте один и тот же адрес, включая порт: `localhost` и `127.0.0.1` считаются
разными хранилищами браузера. Приватный онлайн-сайт и локальная копия также
хранят импортированные проекты независимо.

## Если браузер не открылся

Откройте http://127.0.0.1:4267/ вручную. Если в окне запуска есть ошибка,
проверьте, что архив распакован целиком и рядом со скриптами лежит папка `app`.
При занятом порте закройте прежнее окно запуска. Можно явно выбрать другой порт:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Port 4268
```

С Node.js:

```text
node start-local.cjs --port 4268
```

С Python:

```text
py -3 start-local.py --port 4268
```

При выборе другого порта импортированные проекты прежнего адреса не исчезают,
но становятся видны только после возврата к прежнему адресу.

## macOS / Linux

Нужен установленный Node.js или Python 3.8+. В папке архива выполните:

```bash
sh start-local.sh
```

## Работа с исходниками

Готовую сборку запускать проще всего через файл в корне архива. Для изменений
интерфейса перейдите в `source/`, установите Node.js 20.19+ либо 22.12+ и выполните:

```bash
npm ci
npm test
npm run build
```

Только установка пакетов для разработки требует сети. Новый результат появится
в `source/dist/`. Замените им содержимое корневой папки `app/` и перезапустите
локальный сервер. `source/README.md` описывает структуру графа и обновление данных.

## Область возможностей

Это та же адаптация для готовых JSON-LD, что и опубликованный сайт. Она включает
интерактивный 3D/2D-граф, карточки, требования, источники, поиск фактов по структуре
и ключевым словам, пути, импорт и экспорт пакета Workbench. API-ключ не требуется.
LLM-индексация PDF, embeddings и языковая генерация ответов в архив не включены.

Исследовательская модель по мотивам ГОСТ 13579-2018 не является полной
цифровой копией стандарта. Исходные тексты и значения сохранены как в репозитории.

## Проверка этой поставки

Готовая веб-сборка совпадает с опубликованной версией. Интерфейс проверялся
в браузере при сборке сайта. Локальные серверы Node.js и Python проверены
HTTP-запросами: загрузка страницы, JS/CSS, графа, JSON-LD и экспортного пакета.
Windows-сценарий PowerShell/.NET подготовлен, но в этой Linux-среде не запускался.
